# Compliance and Asset Policy

## License and Model Usage
- 必须在对外文档中声明所用模型、依赖与对应 license。
- 提交示例图时，建议附带 prompt、seed、模型版本与时间。

## Asset Storage Rules
- 仓库内保留：脚本、配置、manifest、轻量样例。
- 大文件（权重、原始大数据包、大量图片）放 LFS 或 Release。
- 禁止提交来源不明或许可证不清晰的数据。

## PR Checklist (Compliance)
- 是否注明模型来源与 license。
- 是否避免提交受限版权资产。
- 是否提供最小可复现命令。
